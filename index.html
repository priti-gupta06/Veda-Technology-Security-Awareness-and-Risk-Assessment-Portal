CYBERSECURITY EDUCATION

Security Awareness

Learn how to recognize and prevent common cyber threats.
✉

Phishing Attacks

Phishing is a cyberattack in which criminals send fraudulent messages to steal information.

  • Verify the sender's email address.
  • Avoid suspicious links.
  • Do not open unexpected attachments.
  • Report suspicious emails.
▣

Password Security

Strong passwords help protect user accounts from unauthorized access.

  • Use long and unique passwords.
  • Enable multi-factor authentication.
  • Never share verification codes.
  • Use an approved password manager.
⌘

Device Protection

Devices should be protected against unauthorized access and malicious software.

  • Install security updates.
  • Lock devices when unattended.
  • Use approved antivirus software.
  • Avoid unknown USB devices.
◉

Data Protection

Confidential information must be handled carefully to prevent accidental disclosure.

  • Share files securely.
  • Restrict access permissions.
  • Maintain backups.
  • Follow data protection policies.
