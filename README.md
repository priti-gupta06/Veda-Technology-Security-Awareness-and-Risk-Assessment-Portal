# Veda-Technology-Security-Awareness-and-Risk-Assessment-Portal

## Project Overview

The Security Awareness and Risk Assessment Portal is a web-based application designed to improve cybersecurity awareness and help users understand common security risks.
The portal aims to provide information about cybersecurity threats, assess potential risks, and suggest basic security practices to improve digital safety.

## Objectives

- Promote cybersecurity awareness.
- Educate users about common cyber threats.
- Identify and assess potential security risks.
- Provide security recommendations.
- Help users understand the importance of safe online practices.

## Key Features

The planned portal includes:

1. Dashboard – Overview of security awareness and assessment activities.
2. Security Awareness – Information about cybersecurity and online safety.
3. Threat Identification – Educational information about phishing, malware, and password attacks.
4. Risk Assessment – Assessment of potential security risks.
5. Risk Classification – Categorization of risks into Low, Medium, and High.
6. Security Recommendations – Suggestions to improve security practices.
7. Reports – Presentation of assessment results.

## Installation and Setup

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the Project Folder

```bash
cd Veda_security_Portal
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

### 4. Activate Virtual Environment

Windows:

```bash
venv\Scripts\activate
```

### 5. Install Dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the Application

```bash
python app.py
```

### 7. Open in Browser

```text
http://127.0.0.1:5000
```
